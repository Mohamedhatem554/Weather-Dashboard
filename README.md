# 🌦️ Weather Dashboard

A responsive web application that displays weather information for cities around the world using a weather API. Built to provide a simple and user-friendly way to explore weather conditions through a clean interface.

## ✨ Features

- 🌍 **Worldwide Weather:** Explore weather information for cities around the world.
- 🌡️ **Weather Information:** View available weather details provided by the API.
- 📱 **Responsive Design:** Designed to work across different screen sizes.
- 🎨 **Clean Interface:** Simple and intuitive user experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mohamedhatem554/Weather-Dashboard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Weather-Dashboard
   ```

3. Open the project using your preferred code editor.

4. Configure your weather API key if required by the API provider.

5. Run the application using a local development server, such as the Live Server extension in Visual Studio Code.
